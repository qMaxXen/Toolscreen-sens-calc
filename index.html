DPI mode explanation

The DPI mode exists to help players who previously used the old Boateye method and have changed their mouse DPI.

With Toolscreen you can keep your original DPI and adjust only the Toolscreen global sensitivity.

By entering your Old DPI (what you used with the old Boateye method) and your New DPI (what you want to use now or used before boateye), the calculator compensates for this difference and outputs a corrected Global Toolscreen sensitivity.

The New Minecraft sensitivity field remains fixed at 0.02291165 regardless of DPI, this is the most optimal value, as it has less pixel skip and higher 360 tolerance.

If you have not changed your DPI before setting up Toolscreen, you do not need to enable this mode.

Cursor Speed mode explanation

This mode is for players who had Raw Input OFF in Minecraft and were not using the default Windows cursor speed.

When Raw Input is disabled, Minecraft applies Windows pointer speed scaling to your mouse movement, which affects how your in-game sensitivity translates to actual movement.

Use the Control Panel field (1–11) if you set your cursor speed via Control Panel > Mouse > Pointer Options.

Use the Settings scale field (1–20) if you set it via Windows Settings > Bluetooth & devices > Mouse.

The default cursor speed is 6 (Control Panel) or 10 (Settings scale). If yours was default, you do not need this mode.

If you played with Raw Input ON, or used the default Windows cursor speed, you do not need to enable this mode.
