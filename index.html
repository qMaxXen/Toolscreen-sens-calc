Toolscreen Sensitivity Calculator

  1. Use the sensitivity from .minecraft/options.txt for the calculator. Find the line that begins with mouseSensitivity.
  2. Put the new Minecraft sensitivity in .minecraft/config/mcsr/standardsettings.json if you have the mod StandardSettings (make sure StandardSettings is enabled and sensitivity is turned on in Minecraft ➔ Options ➔ Book & Quill ➔ StandardSettings). Otherwise, put it in .minecraft/options.txt.
  3. Put the new Minecraft sensitivity in Ninjabrain Bot settings ➔ Optional features ➔ Boat measurement ➔ Sensitivity 1.13+, and enable Green boat.
  4. Put the Toolscreen sensitivity in Toolscreen ➔ Basic ➔ General ➔ Sensitivity ➔ Global.
